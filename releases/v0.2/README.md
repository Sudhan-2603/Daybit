# Daybit v0.2 release

Daybit v0.2 is packaged as a standalone Tauri desktop app. It bundles the frontend, saves tasks in local app storage, and does not start a frontend or backend server.

## Windows

Build on Windows with Rust, Node.js, the Tauri CLI v2, and the Windows desktop build prerequisites installed:

```powershell
powershell -ExecutionPolicy Bypass -File .\releases\v0.2\scripts\build-windows.ps1
```

The build creates `Daybit-v0.2.exe`, `Daybit-Setup-v0.2.msi`, and `SHA256SUMS.txt` under `releases\v0.2\windows`.

To install the standalone executable and create Desktop and Start Menu shortcuts:

```powershell
powershell -ExecutionPolicy Bypass -File .\releases\v0.2\windows\installer.ps1
```

Run the MSI directly for the standard Windows installer.

Release binaries are generated by the build script; this source tree does not contain prebuilt v0.2 packages yet.
